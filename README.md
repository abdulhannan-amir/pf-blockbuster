\## Controls

\- Left / A: move paddle left

\- Right / D: move paddle right

\- Space: launch the ball

\- Esc: save the game and go back to the menu

\- Up / Down / Enter: choose an option in the menu



\## How to Run

1\. Install Visual Studio and download SFML 3.0.2 (Visual C++ 17, 64-bit) to C:\\SFML.

2\. Open the Block Buster solution in Visual Studio.

3\. Select Debug and x64, then press Ctrl + F5.

4\. Make sure level.txt is in the project folder next to main.cpp.
